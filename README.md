# CmdSplit

轻量 macOS 菜单栏窗口工具，通过 Command + 方向键进行左右分屏和窗口最大化。

| 快捷键 | 操作 |
| --- | --- |
| `⌘←` | 当前窗口移到所在屏幕的左半边 |
| `⌘→` | 当前窗口移到所在屏幕的右半边 |
| `⌘↑` | 当前窗口最大化到可用区域，保留菜单栏和 Dock，不进入全屏 |

工具按窗口所在屏幕的可用区域调整大小。重复按左右快捷键仍保持半屏，不循环切换尺寸。安装后登录 Mac 自动启动，意外退出后由系统自动恢复。菜单栏可暂停、恢复快捷键，或关闭工具并停用自动启动。

## 安装

当前提供 **Apple Silicon（arm64）** 版本，构建目标为 macOS 13 或更高版本。

### 使用安装包

从 [v1.1.0 发布页](https://github.com/YugengChen/CmdSplit/releases/tag/v1.1.0) 下载 `CmdSplit-v1.1.0-macos-arm64.zip`，解压后在该文件夹的终端运行：

```bash
bash install.sh
```

安装脚本会将应用放入当前用户的 `~/Applications/CmdSplit.app`，并创建登录自动启动配置。安装不需要管理员权限；窗口控制权限须在 macOS 系统设置中授予。

预编译应用使用本地 ad hoc 签名，未经过 Apple 公证。也可以使用下面的方法从源码构建。

### 从源码构建

需要 Xcode 或 Xcode Command Line Tools 提供的 Swift 编译器。

```bash
git clone https://github.com/YugengChen/CmdSplit.git
cd CmdSplit
bash build.sh
bash install.sh
```

`build.sh` 在临时目录中编译和签名，生成 `CmdSplit.app.zip`。在云同步文件夹中直接签名应用包可能受文件元数据影响，构建脚本使用临时目录避免这一问题。

## 系统权限

安装后，在 **系统设置 → 隐私与安全性 → 辅助功能** 中开启 `CmdSplit`。部分系统版本将此页面显示为“设备控制和数据访问”。菜单栏中的“辅助功能权限…”可以打开对应设置。

更新或重新编译后，如果快捷键未生效，请在该页面移除旧的 `CmdSplit`，重新添加 `~/Applications/CmdSplit.app`，再开启权限。

## 使用与限制

- 这些全局快捷键会接管应用原有的 `⌘←`、`⌘→`、`⌘↑` 操作；需要原有行为时可在菜单栏暂停快捷键。
- 窗口自身的最小尺寸或不可调整大小的窗口可能限制分屏效果。
- 多屏时优先使用与窗口重叠面积最大的屏幕。
- 工具使用 macOS 的辅助功能和全局快捷键接口，运行不需要网络连接。

## 停用和卸载

菜单栏的“关闭并停用自动启动”会停止工具并移除自动启动配置。再次运行 `install.sh` 可重新启用。

卸载时，在项目或安装包文件夹中执行：

```bash
bash uninstall.sh
```

卸载脚本停止后台任务、移除自动启动配置，并将应用移至废纸篓。

## 项目文件

| 文件 | 用途 |
| --- | --- |
| `CmdSplit.swift` | 菜单栏、全局快捷键和窗口操作 |
| `Info.plist` | 应用信息和版本 |
| `build.sh` | 编译并生成应用压缩包 |
| `install.sh` | 安装并启用登录自动启动与自动恢复 |
| `uninstall.sh` | 停止和卸载工具 |
| `使用说明.txt` | 安装包随附说明 |

## 验证

v1.1.0 在 Apple Silicon、macOS 27.0.1 上验证了左右分屏、普通窗口最大化，以及后台进程退出后自动恢复三组快捷键。最大化测试确认窗口的 `AXFullScreen` 状态为 `false`。登录自动启动配置已检查，未通过实际重启整台 Mac 进行验证。
